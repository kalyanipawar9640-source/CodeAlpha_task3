# CodeAlpha Task 4 - Hotel Reservation System

Java Swing desktop project for the CodeAlpha Java Programming Internship.

## Requirements covered
- Search, book and manage hotel rooms
- Standard, Deluxe and Suite categories
- Make and cancel reservations
- Booking details view
- Simulated payment
- OOP design
- Java File I/O for rooms and bookings

## Run in VS Code
Open the project root in VS Code, then Terminal > New Terminal:

```cmd
javac -d out src\*.java
java -cp out HotelReservationApp
```

The `data` folder and text files are created automatically.

## Main file
`src/HotelReservationApp.java` is the main class and starts the GUI.

Submit the complete project ZIP/folder, not only the main Java file.
